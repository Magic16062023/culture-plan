# Культурный план

Приложение запускается через встроенный в Python сервер, хранит мероприятия в SQLite и отправляет email-напоминания в фоновом режиме.

В карточке мероприятия можно указать HTTPS-ссылку на внешний сервис продажи билетов. Она отображается пользователям кнопкой «Купить билеты» и передаётся в ICS-подписку Яндекс Календаря.

## Запуск

В PowerShell из папки приложения:

```powershell
$env:SMTP_HOST="smtp.example.ru"
$env:SMTP_PORT="587"
$env:SMTP_USERNAME="calendar@example.ru"
$env:SMTP_PASSWORD="пароль-приложения"
$env:SMTP_FROM="calendar@example.ru"
$env:ADMIN_USERNAME="admin"
$env:ADMIN_PASSWORD="надёжный-пароль"
$env:ADMIN_EMAIL="admin@example.ru"
$env:PUBLIC_BASE_URL="https://calendar.example.ru"
$env:VK_CLIENT_ID="идентификатор-приложения"
$env:VK_REDIRECT_URI="https://calendar.example.ru/api/auth/vk/callback"
python server.py
```

Затем откройте `http://127.0.0.1:8000`. Не открывайте `index.html` напрямую: в этом режиме серверное хранение и уведомления недоступны.

## Android

Исходники Android-клиента находятся в `android-client/`, обновлённый APK — в `dist/culture-plan-android-fixed.apk`. Клиент поддерживает Android 7.0 и новее, автоматически открывает постоянный адрес опубликованной версии, поддерживает регистрацию зрителя, авторизацию, VK ID (при его настройке) и выбор файлов афиши. Раздел «Места» доступен и в приложении.

Для подключения телефона в локальной сети запустите сервер с `$env:APP_HOST="0.0.0.0"` и укажите в клиенте LAN-адрес компьютера, например `http://192.168.1.25:8000`. Для Android Emulator используется `http://10.0.2.2:8000`. Подробности сборки и подключения приведены в `android-client/README.md`.

## Полная версия на Vercel

Постоянный адрес опубликованного приложения: `https://vercel-preview-merqurys-5851.vercel.app`. Публичная афиша и раздел «Места» доступны без входа; каталог профилей и ссылки на фотографии хранятся в `places.json` (на сайте показываются фотографии с указанием первоисточников).

Для работы входа, регистрации и редактирования на Vercel подключите постоянную базу Neon PostgreSQL к проекту и окружениям Production и Preview. Не загружайте на Vercel `calendar.db`: команда `python build_vercel_app.py` создаёт отдельный пакет `vercel-app/` с веб-интерфейсом, API, каталогом мест и публичными мероприятиями (без персональных данных локальных пользователей). Задайте `DATABASE_URL`, `ADMIN_PASSWORD` и `PUBLIC_BASE_URL` в Production. Разверните пакет командой `vercel deploy vercel-app --prod -y --scope merqurys-5851`.

Публичные мероприятия и афиши импортируются в новую базу только при первом запуске; дальнейшие изменения сохраняются в PostgreSQL. Фоновые email-уведомления локального сервера не запускаются автоматически в Vercel Functions: для них нужен отдельный планировщик.

Для Gmail используется `smtp.gmail.com`, порт `587` и пароль приложения. Для Яндекс Почты используется `smtp.yandex.ru`, порт `465`; дополнительно задайте `$env:SMTP_SSL="true"`.

## Уведомления

После первого запуска войдите под учётной записью администратора. Если переменные `ADMIN_USERNAME` и `ADMIN_PASSWORD` не заданы, используются `admin` и `admin123`. Обязательно измените этот пароль через раздел «Пользователи» или задайте безопасный пароль до первого запуска.

## Роли

- **Администратор**: управление всеми мероприятиями, уведомлениями и пользователями.
- **Руководитель**: просмотр всех мероприятий и создание уведомлений, без добавления, редактирования и удаления мероприятий.
- **Пользователь**: создание мероприятий и управление только собственными мероприятиями.
- **Куратор**: создание мероприятий и управление мероприятиями своего направления; уведомления можно назначать себе и руководителям.
- **Зритель**: просмотр мероприятий и синхронизация с Яндекс Календарём, без создания, изменения, удаления и экспорта мероприятий.

Администратор создаёт учётные записи, задаёт роли, телефон, email и направление куратора в разделе «Пользователи». Зритель также может зарегистрироваться самостоятельно по телефону или email и затем использовать эти данные для входа.

## VK ID

Для входа через VK ID зарегистрируйте веб-приложение в кабинете VK ID и добавьте точный доверенный адрес возврата. Задайте `VK_CLIENT_ID` и `VK_REDIRECT_URI`; последний должен совпадать с адресом в настройках VK. Если `VK_REDIRECT_URI` не задан, используется `${PUBLIC_BASE_URL}/api/auth/vk/callback`. Кнопка VK ID отображается только при полной настройке.

Для приложений, которым VK выдал сервисный токен, его можно передать через `VK_SERVICE_TOKEN`. Авторизация использует OAuth 2.1 Authorization Code Flow с PKCE; сервисный токен не сохраняется в браузере.

## Уведомления

Администратор, руководитель или куратор открывает карточку мероприятия и нажимает «Создать уведомление». Доступны сроки: в день события либо за 1, 3, 7 или 14 дней. Email получателя берётся из его учётной записи. Сервер проверяет события каждые пять минут и записывает факт отправки в `calendar.db`, поэтому повторное письмо не отправляется.

Сервер должен быть запущен в момент проверки. Для постоянной работы его можно разместить на сервере/VPS или настроить автоматический запуск `server.py` в Windows.

## Яндекс Календарь

Каждый пользователь может создать собственную секретную ICS-ссылку кнопкой «Яндекс Календарь». Эту ссылку нужно один раз добавить в Яндекс Календаре через «Новый календарь» → «По ссылке». Яндекс периодически загружает актуальный список мероприятий автоматически.

Для синхронизации сервер обязательно должен быть доступен из интернета по постоянному HTTPS-адресу. Укажите его в `PUBLIC_BASE_URL`. Адрес вида `http://127.0.0.1:8000` доступен только на текущем компьютере, поэтому серверы Яндекса открыть его не смогут.

Ссылка содержит секретный токен. Не публикуйте её. При создании новой ссылки предыдущая автоматически перестаёт работать; ссылку также можно отозвать вручную.

## Настройки

- `APP_HOST` — адрес сервера, по умолчанию `127.0.0.1`.
- `APP_PORT` — порт, по умолчанию `8000`.
- `NOTIFICATION_CHECK_INTERVAL` — интервал проверки в секундах, по умолчанию `300`.
- `SMTP_SSL=true` — использовать SMTP поверх SSL вместо STARTTLS.
- `ADMIN_USERNAME`, `ADMIN_PASSWORD`, `ADMIN_EMAIL` — параметры первого администратора; применяются только при создании первой учётной записи.
- `PUBLIC_BASE_URL` — публичный HTTPS-адрес приложения для подписок Яндекс Календаря.
- `VK_CLIENT_ID` — идентификатор веб-приложения VK ID.
- `VK_REDIRECT_URI` — доверенный callback URL VK ID; необязателен при заданном `PUBLIC_BASE_URL`.
- `VK_SERVICE_TOKEN` — сервисный токен VK ID, если он требуется настройками приложения.
- `APP_TIMEZONE` — часовой пояс мероприятий в ICS, по умолчанию `Europe/Moscow`.

Не сохраняйте SMTP-пароль в HTML или в файлах, доступных через веб-сервер.

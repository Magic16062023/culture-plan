# Android-клиент «Культурный план»

Клиент открывает существующее серверное приложение в защищённой Android WebView. При первом запуске он запрашивает адрес сервера и сохраняет его только на устройстве.

## Готовый APK

Установочный файл находится в `../dist/culture-plan-android-1.0.0.apk`. Это недебажная release-сборка, подписанная тестовым Android-сертификатом и предназначенная для прямой установки. Для публикации в RuStore или Google Play создайте собственный постоянный release-ключ и подпишите сборку им.

Минимальная версия системы — Android 7.0 (API 24).

## Подключение

1. Запустите сервер так, чтобы он принимал подключения из сети:

   ```powershell
   $env:APP_HOST="0.0.0.0"
   python server.py
   ```

2. На физическом телефоне укажите адрес компьютера в локальной сети, например `http://192.168.1.25:8000`. Адрес `127.0.0.1` на телефоне указывает на сам телефон.
3. В стандартном Android Emulator используйте `http://10.0.2.2:8000`.
4. Для доступа через интернет используйте постоянный HTTPS-адрес. Он также необходим для VK ID и синхронизации с Яндекс Календарём.

Windows Firewall должен разрешать входящие подключения к выбранному порту. Открытый HTTP допустим только в доверенной локальной сети; для рабочего размещения используйте HTTPS.

Кнопка «Сервер» в верхней панели клиента позволяет сменить адрес. При смене адреса локальные cookies авторизации удаляются.

## Самостоятельная сборка

Требуются JDK 17 и Android SDK с Platform 35 и Build Tools 35.0.0. Задайте `ANDROID_HOME`, затем выполните:

```powershell
./gradlew.bat assembleDebug
```

Результат появится в `app/build/outputs/apk/debug/app-debug.apk`.

Клиент не содержит Python-сервер или базу SQLite. Сервер из корня проекта должен работать отдельно и быть доступен устройству по сети.

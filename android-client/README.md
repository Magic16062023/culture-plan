# Android-клиент «Культурный план»

Клиент открывает существующее серверное приложение в защищённой Android WebView. При первом запуске подключается к опубликованной полной версии проекта на Vercel; адрес сервера сохраняется только на устройстве.

## Готовый APK

Обновлённый установочный файл находится в `../dist/culture-plan-android-fixed.apk`. Он подписан тем же тестовым Android-сертификатом, что и прежняя версия, и предназначен для прямой установки поверх неё. Для публикации в RuStore или Google Play создайте собственный постоянный release-ключ и подпишите сборку им.

Минимальная версия системы — Android 7.0 (API 24).

## Подключение

1. Запустите сервер так, чтобы он принимал подключения из сети:

   ```powershell
   $env:APP_HOST="0.0.0.0"
   python server.py
   ```

2. Для опубликованной версии просто откройте приложение при работающем интернете. При необходимости нажмите «Сервер» и укажите постоянный адрес `https://vercel-preview-merqurys-5851.vercel.app`. При обновлении APK сохранённый адрес старого разового preview автоматически заменяется постоянным; собственный адрес сервера сохраняется.
3. Для собственного локального сервера на телефоне укажите адрес компьютера в локальной сети, например `http://192.168.1.25:8000`. Адрес `127.0.0.1` на телефоне указывает на сам телефон.
4. В стандартном Android Emulator используйте `http://10.0.2.2:8000` только при работающем локальном сервере.
5. Для собственного доступа через интернет используйте постоянный HTTPS-адрес. Он также необходим для VK ID и синхронизации с Яндекс Календарём.

Windows Firewall должен разрешать входящие подключения к выбранному порту. Открытый HTTP допустим только в доверенной локальной сети; для рабочего размещения используйте HTTPS.

Кнопка «Сервер» в верхней панели клиента позволяет сменить адрес. При смене адреса локальные cookies авторизации удаляются.

Кнопка «Регистрация» открывает форму самостоятельной регистрации зрителя по телефону или email. После отправки формы пользователь автоматически входит в аккаунт. Регистрация работает на полной версии Vercel и на работающем основном сервере (`server.py`).

## Самостоятельная сборка

Требуются JDK 17 и Android SDK с Platform 35 и Build Tools 35.0.0. Задайте `ANDROID_HOME`, затем выполните:

```powershell
./gradlew.bat assembleDebug
```

Результат появится в `app/build/outputs/apk/debug/app-debug.apk`. При отсутствии полного Gradle/Android SDK соберите совместимый APK скриптом `python rebuild_apk.py <путь-к-r8.jar>` из каталога `android-client/` при заданных `ANDROID_HOME` и `JAVA_HOME`. Скрипт использует ресурсы исходного `../dist/culture-plan-android-1.0.0.apk` и подписывает сборку локальным тестовым ключом.

Клиент не содержит Python-сервер или базу SQLite. Сервер из корня проекта должен работать отдельно и быть доступен устройству по сети.
